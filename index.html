My IP Info

Multi-source IP intelligence and network connectivity diagnostic suite.

Multi-Source IP Cross-Validation

Most IP lookup utilities query a single server. My IP Info cross-validates client IP and network telemetry across Cloudflare Edge, public IP providers (ipify, ipwho.is, IP.SB, ip.guide, SeeIP, icanhazip, IPIP.net), and browser WebRTC STUN candidates to diagnose VPN/proxy bypasses, detect coordinate variance across geolocation databases, and measure round-trip latency.

Fast CLI Terminal Access

Query your IP directly from your terminal with curl or wget:

# Plain public IP
curl -sL https://my-ip-info.ii2d-dev.workers.dev

# Formatted JSON diagnostic info
curl -sL https://my-ip-info.ii2d-dev.workers.dev/api/v1/info?format=json

# YAML metadata
curl -sL https://my-ip-info.ii2d-dev.workers.dev/api/v1/info?format=yaml

Comprehensive Diagnostics

  • Zero-Latency Edge Geolocation: Extracts city, region, coordinates, and ASN directly from TLS connection headers.
  • WebRTC STUN Leak Detection: Interrogates browser ICE candidates to detect unencrypted IP leaks across VPNs.
  • DNS Leak Inspection: Resolves unique nonce queries to uncover upstream recursive DNS resolvers.
  • Privacy Focused: Zero server-side IP logging and 100% on-device local storage history.
